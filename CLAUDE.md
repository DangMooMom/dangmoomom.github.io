# Jihyun's portfolio site

Static site. Plain HTML, CSS, JS. No frameworks, no build step.
Hosted on GitHub Pages. Pushing to the `draft` branch publishes it live.

## Files
- index.html: home
- projects/*.html: case study pages (company-directory, purchase-order, inbox)
- assets/css/style.css: all styles. Design tokens are CSS variables in :root
- assets/js/main.js: carousel and scroll reveal
- images/: cd/, po/, inbox/ per project

## Rules
- Never push or merge to `draft` unless I say "deploy".
- Before changing copy, use the portfolio-copy skill.
- Before changing layout, spacing or type, use the site-layout skill.
- After any change, tell me which page to open and what to check, on desktop and mobile width.
- Never invent results, numbers or claims. If unsure, ask me.
